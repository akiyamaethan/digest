# Barry the Last Bass

> **Playable Web Build:** [Play on Unity Play](https://play.unity.com/en/games/643b8606-dcc1-4bbc-af1d-677ae6e740d9/barry-the-last-bass)  
> **Engine Version:** `Unity 6000.2.8f1` (Unity 6)  
> **Author:** Ethan Akiyama  

---

## Overview

*It's a busy day on the lake, and Barry the Bass is the last fish left! Fish and Wildlife Service is nowhere to be found. Play as Barry to avoid the onslaught of hooks from distraught fishermen while trying to keep your tummy full.*

**Barry the Last Bass** is an arcade survival game built in Unity 2D where players navigate Barry through treacherous waters, dodging swinging fishing hooks, nibbling off bait to prevent starvation, and catching heart-fish to stay alive.

---

## Controls

| Input | Action |
|---|---|
| **Mouse Cursor** | Steer Barry (Barry swims toward cursor with dynamic rotation & deadzone) |
| **Contact / Collision** | Nibble bait off hooks / Eat power-ups |
| **<kbd>Esc</kbd>** | Pause / Resume / Return to Title |

---

## Running the Project

1. Clone or download the repository.
2. Open the project in **Unity 6000.2.8f1** (or compatible Unity 6 release).
3. Open `Assets/Scenes/TitleScreen.unity` or `Assets/Scenes/GameScene.unity` and hit **Play**.
